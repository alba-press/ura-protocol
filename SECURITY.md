# Security policy

## Scope

This repository contains public architecture and status documentation. It does not contain Ura's production application, operator infrastructure, private keys or deployment configuration.

## Reporting a vulnerability

Do not publish security-sensitive findings, credentials, private endpoints or reproducible exploit details in a public issue.

Contact Ura Labs through the official website at [ura.finance](https://ura.finance) and clearly mark the message as a security report. Include only the minimum information needed to establish contact. Sensitive technical material should be exchanged only after a private channel is confirmed.

Public GitHub issues may be used for non-sensitive documentation errors.

## No security guarantee

Preprod demonstrations, public documentation and issue reports do not constitute an independent security audit or a production-readiness guarantee.
