# Wallet and SDK collaboration request

## One named ask

Ura needs one named wallet or SDK technical owner for a focused working session that completes a single end-to-end Preprod NIGHT redesignation transaction.

## Required transaction

A NIGHT holder reviews and signs an authorization that:

1. selects the intended NIGHT UTXO or UTXOs;
2. directs future DUST generation to Ura's receiver;
3. leaves NIGHT in the holder's wallet;
4. is submitted on Preprod;
5. produces observable post-transaction receiver and registration evidence.

## What already works

- Ura's Model B sponsored-execution path;
- the warm operator execution path;
- bounded request policy and reconciliation work;
- the ADA/tADA Privacy Bridge route on Preprod.

A partner that merely consumes Ura's DUST does not resolve the current blocker. The missing proof is the holder-wallet supply-side authorization.

## Working-session output

The session is complete only when it produces:

- wallet-reviewed transaction intent;
- holder signature through the supported connector path;
- submitted Preprod transaction identifier;
- before-and-after registration observations;
- receiver confirmation;
- sanitized, reproducible evidence;
- a named owner for any remaining connector or SDK defect.

## Security boundary

No private keys, wallet seeds or production credentials will be shared. Evidence will be sanitized before publication.
